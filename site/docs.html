the contract

Markup in. Behavior out.

Manner is a tiny custom element that upgrades authored tabs. Start with ordinary HTML, then add one module when you want focus management, selection state, and keyboard interaction.

01 / install

One dependency. One import.

Install Manner from npm, then import it once from your application entrypoint. The package has no runtime dependencies.

npm install manner

import "manner";

The default entrypoint registers <manner-tabs>. To register the same behavior under a custom tag, import the element class:

import { MannerTabs } from "manner/element";
customElements.define("my-tabs", MannerTabs);

02 / markup

Choose the profile that matches the page.

Progressive anchors

Use anchors when tabs represent URL-addressable content. Before JavaScript loads, each link still navigates to its panel.

<manner-tabs>
  <nav data-tablist aria-label="Topics">
    <a href="#news" data-tab>News</a>
    <a href="#events" data-tab>Events</a>
  </nav>
  <section id="news" data-panel>…</section>
  <section id="events" data-panel>…</section>
</manner-tabs>

Application buttons

Use buttons for in-place application state. Add data-activation="manual" when selection should happen on Enter or Space.

<manner-tabs data-activation="manual">
  <div data-tablist role="tablist">
    <button data-tab>Overview</button>
    <button data-tab>Settings</button>
  </div>
  …
</manner-tabs>

03 / api

Small surface area, inspectable state.

The element owns the interaction lifecycle. Your HTML remains the source of truth for labels, panel content, and IDs.

SurfaceWhat it does
selectedIndexRead or set the active tab index.
select(index)Select a tab and update its panel relationships.
refresh()Re-discover authored tabs and panels after DOM changes.
manner-tabs-changeCustom event emitted after a selection change.
data-activationauto (default) or manual.
data-orientationhorizontal (default) or vertical.
manner-form.validate()Validate a form and synchronize its author-owned errors.
manner-form.refresh()Re-discover deliberate form DOM changes.

forms / next release

Native validation, coordinated errors.

<manner-form> keeps the browser's constraint validation as its source of truth. It only coordinates your summary, field errors, ARIA relationships, and first-invalid focus.

<manner-form>
  <form>
    <div data-error-summary hidden tabindex="-1">…</div>
    <label for="email">Email</label>
    <input id="email" type="email" required>
    <p id="email-error" data-error-for="email" hidden>…</p>
  </form>
</manner-form>

04 / keyboard

Predictable movement.

  • Arrow Right / Left move through horizontal tabs.
  • Arrow Down / Up move through vertical tabs.
  • Home and End move to the first or last tab.
  • Movement wraps at either end.
  • Tab exits the tablist; Shift + Tab re-enters it from the previous focusable element.
  • In automatic mode, focus selects immediately. In manual mode, Enter or Space commits the focused tab.

05 / accessibility

Evidence you can inspect.

The release suite covers 45 browser tests across Chromium, Firefox, and WebKit, including focus, activation, nested instances, reconnects, generated IDs, malformed markup, and axe checks on canonical fixtures. ARIA snapshots assert the exposed structure.

Automated checks are not a substitute for assistive technology testing. The manual matrix for Safari + VoiceOver, Firefox + NVDA, and Chrome + NVDA remains a release gate.

06 / when not to use it

Use the platform when it already fits.

Manner is for tabbed content, not a general-purpose overlay or navigation system.

  • Use <details> for a single disclosure.
  • Use <dialog> for modal or non-modal dialogs.
  • Use native <select> for choosing one option from a list.
  • Use links or navigation landmarks for page navigation.

Popover and Anchor Positioning can solve other UI problems, but they do not automatically create an accessible tab or menu pattern.
